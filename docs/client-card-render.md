## 0. 三种视角的定义（全文统一）

| 代码 | 情形 | 屏幕上的「我」是谁 | 服务端 CARD_PLAYED 的 source/target |
|---|---|---|---|
| **V1** | 我自己对人机 A 用牌 | 底部主视角席位（`game_room_screen.dart:3534-3572`，`isMe:true`） | source = 我，target = A |
| **V2** | 人机 A 对我用牌 | 同上，但我在 targetIds 里 | source = A，target = 我 |
| **V3** | 人机 A 对人机 B 用牌（我旁观） | 同上，我既非 source 也非 target | source = A，target = B |

三名玩家时 V3 就是「我不是使用者也不是目标」的一切情形。人机 B 的席位在圆桌上方/左侧，A、B 由 `GameContext` 分配席位顺序决定，客户端只按座位序号布局（`game_room_screen.dart:2847-2873`）。

### 0.1 关键结构：屏幕上有 5 个「落点」

| 落点 | 位置 | 定义处 |
|---|---|---|
| 中央结算区 | `Align(0, 0.70)`，牌 128×180，最多 4 张横排 | `game_room_screen.dart:2994-3055`、`center_stage_view.dart:31-32` |
| 我的席位卡 | 底部中央，`compact:true` | `game_room_screen.dart:3534-3572` |
| 底部主视角光束点 | `Offset(boardW - sw/2 - 12, boardH - 6)` | `game_room_screen.dart:2882-2894` |
| 席位飘字层 / 爆点层 | 以席位卡中心为原点 | `game_room_screen.dart:3636-3713`、`3715-3747` |
| 屏幕中央大字 `_flash` | 56px，1100ms | `game_room_screen.dart:2234-2243`、`3681-3705` |

**要点**：V1/V2 里「我自己」的席位不是圆桌上的普通席位，而是底部那张 compact 卡；光束射向我时终点就是底部那个点（`:2884-2894`）。所以**「我对我自己用牌」（桃/酒/无中生有/闪电）时 from == to，光束长度为 0 → 屏幕上看不到箭头** —— 需实机确认是否真的一条都看不到。

## 1. 通用渲染管线（先看这一节，后面每张牌只写差异）

### 1.1 一张牌被打出 → 我屏幕上依次发生什么

1. 服务端广播 `BROADCAST_MSG` 文本（`GameContext.java:414-420`），客户端先进 `_parseBroadcastLog` 做「正则特判」，再把原文塞进日志（`game_room_screen.dart:273-277`）。
2. 服务端广播结构化 `CARD_PLAYED`（`GameContext.java:464-494`），客户端 `_handleCardPlayed`（`game_room_screen.dart:433-551`）：
   - `playCard(cardName)` → **只会播 `play` 一种音效**（`audio_service.dart:110-112`）；
   - 中央结算区 push 一张 128×180 牌面，3200ms 后清 source/target，3400ms 后移除该张（`:515-517`、`:541-550`）；
   - 光束按目标数逐条点亮，**间隔 120ms**（`:491-496`）；光束是**静态渐变线**，没有流动动画（`target_arrow_painter.dart:74-147`）；
   - 出牌者席位 → 中央结算区飞一张 86×122 的牌，arc 46（`:519-540`），**任何人出牌都有**；
   - 若 nature ∈ SHA 类且有目标 → `_waitingForDodge = true`（`:485`），中央下方出现「等待 X 响应【闪】…」胶囊，2600ms 后自动消失（`:497-501`、`:3029-3050`）；
   - 若 targetIds 含**我** → 整个牌桌套 5px `redAccent`（α 0.75）红框警示（`:3094-3105`）；
   - 南蛮/万箭/桃园 → 顶部横幅 1700ms（`:503-514`、`:3057-3093`）。
3. 若服务端**没有**发 CARD_PLAYED（例如「闪」「无懈可击」是响应阶段打出的），客户端退化为**文本猜牌**：日志里出现「使用了/打出/装备了」+ 30 项牌名表白名单匹配 → 中央结算区追加一张牌 3.4s（`:1034-1105`），并用 `对 (.*?) (使用|发起)` 猜目标名。**若距上一次 CARD_PLAYED 不足 800ms 则整段跳过**（`:1087-1089`）。

### 1.2 所有「席位上看得见的东西」的触发源（只认日志文本）

| 日志文本特征 | 席位表现 | 定义处 |
|---|---|---|
| `✔ X 打出 … 躲避了攻击！` | 「已抵消」印章 1400ms + 席位飘字「已抵消」#80DEEA + 光束立即消失 + `shield` 音效 | `:934-949`（服务端只 `CombatResolver.java:305` 会发） |
| `⚔ X 受到 N 点伤害（火焰/雷电）` | 席位闪红 520ms（`_hitSeats`）+ 飘字 `-N` + `damage` 音效；火焰→橙爆点 #FF6D00、雷→紫 #7C4DFF、传导→紫 #B39DDB | `:956-975`、`:658-664` |
| `❤ X 回复 N 点体力` | 飘字 `+N` 绿 + `heal` 音效 + 一张「桃」从中央飞回该席位 | `:976-1001` |
| `🛡 X 的【护甲】抵消了 N 点伤害` | 飘字 `🛡N` #90CAF9 + `shield` | `:1002-1011` |
| `🛡 X 获得 N 点【护甲】` | 飘字 `+🛡N` #64B5F6 + `shield` | `:1012-1021` |
| `【八卦阵】/【仁王盾】/【藤甲】/【白银狮子】` | 飘字（八卦阵判定/仁王盾生效/藤甲生效/白银狮子）#90CAF9 + `shield` 0.7 | `:917-932` |

| `X 挑选了 Y。` | 屏幕中央大字「X 选走了 Y」#FFC94D + 席位飘字牌名 + `draw` 0.5 | `:1024-1032` |

### 1.3 音效清单（全部 11 个）

`{'play','draw','damage','heal','shield','judge','click','turn','win','lose','skill'}`（`audio_service.dart:29-32`）。
**没有任何逐牌音效**：`playCard(cardName)` 的实现就是 `playSfx('play', 0.85)`（`audio_service.dart:110-112`），参数被丢弃。`playVoice(...)` 是空实现（`:106-107`），语音整体关闭。所以「杀 / 桃 / 五谷 / 装备」在我耳朵里全是同一个 `play`。

### 1.4 日志着色（`battle_log_view.dart:14-32`）

- 含 `阵亡`/`受到`/`濒死` → `#FF6B6B` 红
- 含 `回复`/`护甲`/`摸` → `#6BE39B` 绿
- 含 `★`，或（含 `【` 且不含 `轮`） → `#FFD166` 金
- 含 `回合`/`阶段` → `#7FD1FF` 蓝
- 其余 `#BFBFBF` 灰；以 `★`/`⚔`/`💀` 开头或含「回合」→ 加粗
- `>>>>>>>>` 回合分隔行 → 独立蓝底 + 左边框（`:52-70`）

### 1.5 手牌置暗（只影响我自己的手牌）

`_isCardPlayableNow`（`game_room_screen.dart:2246-2310`）+ `hand_card_area.dart:88-101`（`Opacity(0.34)` + 灰度 ColorFilter(0.3)）。规则：

| 场合 | 结论 |
|---|---|
| 弃牌阶段 | 全部可点（不置暗） |
| 自己有 `_activeSkill` | 基本不置暗 |
| 响应阶段（按提示串关键词） | 含 `【闪】` 且不含 `视为【杀】` → 只有【闪】（龙胆时含杀类、武圣时含红牌）；含 `打出【杀】`/`一张【杀】`/`视为【杀】` → 杀类 / 武圣红牌 / 龙胆闪；含 `【桃】` → 桃，或酒（提示也含 `【酒】` 时）；含 `【无懈可击】` → 无懈；**其余一律不置暗** |
| 自己出牌阶段 | 闪、无懈 → 永远置暗；桃 → 仅 `_hp < _maxHp`；杀类 → `_shaLeft > 0`；酒 → `_shaLeft > 0 || _hp < _maxHp`；其余全亮 |

### 1.6 距离不足灰标 / 闪红 / 准星

- 「距离不足」灰标只在**我选中【杀】系牌进入选目标阶段**时出现在**对手**席位（`game_room_screen.dart:2905-2912` → `table_seat_card.dart:809-824`：7.5px 字、`#CC2A2A2A` 底）；边框同时变 `0x55FFFFFF`（`:551-563`）。
- 席位受击闪红：边框 `#FF1744` 宽 3.2 + `boxShadow 0xCCFF1744 blur26`（`table_seat_card.dart:551-563`），520ms。
- 选中【杀】时底部会出现准星线 `_AimLinePainter`（`game_room_screen.dart:3639-3652`）—— 需实机确认观感。

### 2.2 火杀（FIRE_SHA）

与【杀】完全相同，只有 4 处差异：

## 9. 一句话总结

- **V1（自己出牌）**：中央出一张牌 + 一条与牌种对应的彩色光束 + 出牌飞行 + `play` 音效 + 金色日志；后续结算全部靠**服务端纯文本**驱动飘字/闪红/爆点/印章；亲手操作时额外有选目标/选牌弹窗。
- **V2（AI 对我出牌）**：与 V1 同构，但**整桌会套 5px 红框**、光束终点变成底部主视角点、席位反馈落在我自己的底部席位卡上、我进入响应阶段（手牌大量置暗）。
- **V3（AI 对 AI 出牌）**：**没有任何弹窗（除判定/五谷/无懈询问）**，无红框；且**凡涉及「看别人的牌」的动作（过河拆桥/顺手牵羊/火攻弃牌）我只看得到牌背**，信息量与牌名只在日志里。
