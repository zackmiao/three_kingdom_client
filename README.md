# 三国杀 · 局域网联机（Flutter 客户端）

配套服务端见 `../Three_Kingdom`（Java 17，默认端口 9050）。客户端只做渲染与输入，
所有规则结算都在服务端完成，因此客户端可以重连、可以观战、可以被替换。

## 运行

```bash
flutter pub get
flutter run -d windows       # 或 -d macos / -d linux
```

打包：

```bash
flutter build windows --release
```

登录页填写服务端 IP（本机 `127.0.0.1`）、端口（`9050`）和昵称即可。

## 界面

| 页面 | 说明 |
| --- | --- |
| 登录页 `main.dart` | 连接服务端、握手、进入大厅 |
| 大厅 `views/lobby_screen.dart` | **模式选择**（身份场 / 2v2 / 斗地主）、建房 / 加入房间、武将图鉴入口，断线自动重连 |
| 房间 `views/room_screen.dart` | 座位格、**抽将面板**（3 选 1，可重抽）、房主切换模式、准备、房主加/删 AI、开局 |
| 对局 `views/game_room_screen.dart` | 圆桌布局、手牌区、装备/判定区、身份牌、操作倒计时、**手气卡**弹窗 |
| 武将图鉴 `views/hero_book_screen.dart` | 全部武将网格 + 扩展包筛选 + 技能原文详情（大厅与房间都能进） |

### 三种模式

大厅顶部的三张卡片决定本局模式，房主在房间里也能用底栏的模式按钮切换（切换会按模式重置人数：2v2 固定 4 人、斗地主固定 3 人）：

- **身份场**：主公 / 忠臣 / 反贼 / 内奸，2~8 人，只有主公与阵亡者身份公开；
- **2v2**：暖方 2 人 对 冷方 2 人，座位交替站位，阵营身份全员公开；
- **斗地主**：地主 1 人（体力上限 +1、起手多摸 1 张）对 农民 2 人，阵营身份全员公开。

对局内左上角的局势面板会按模式显示 `主/忠/反/内`、`暖方/冷方` 或 `地主/农民` 的人数统计。

### 抽将与手气卡

- 房间里**不再选将**：加入/加 AI 后服务端只下发候选，房间底栏显示「开局后选将 · 候选中 N 名」。
- 点「开始游戏」后进入**选将阶段**：服务端通过 `ASK` 发 `HERO_CANDIDATES`，客户端弹出抽将面板
  （三张立绘卡片，点卡片即确认），结果用 `RESPOND_CARD` 回传武将名；45 秒未选自动取第一位。
- 选将结束后弹出**手气卡**面板：显示当前起手牌与剩余次数（默认 4 次），
  「换一副起手牌」回 `1`，「就用这手牌」回 `0`。

### 选将面板

服务端在登录/进房时下发 `HERO_LIST`，客户端据此渲染选将面板与武将图鉴：

- 6 列将面缩略图（图片来自 `assets/heroes/`，缺失时自动退化为势力色渐变 + 姓名）；
- 顶部按扩展包筛选（全部 / 标准 / 谋攻篇-能包 / 知包 / 同包 / 识包 / 虞包）；
- 底部实时显示所选武将的势力、体力与技能原文；
- 已被其他玩家占用的武将不再出现（不可重复选将）。
- 大厅与房间都能打开「武将图鉴」，浏览全部武将的立绘、势力、体力与技能原文。

### 对局内

- **将面立绘**直接铺在席位卡上，配合体力条、身份徽记、距离提示（距N）、横置/标记与阵亡遮罩；
- **牌在飞**：任何人摸牌（牌背从牌堆飞向该席位）、出牌（牌从出牌者席位飞向中央结算区）、
  弃牌（手牌飞向弃牌堆）、上装备（牌飞向装备栏）都有滑动动画，己方与对手一视同仁；
- 谋攻篇主动技（武圣 / 乱击 / 突袭 / 扬威 / 国色 / 明策 …）以技能按钮形式出现，点按钮后按提示选牌/选目标再点“确定”；
- **技能按钮三态**：可发动（金色发光）、本回合/本轮已用过（置暗 + 显示「已用」，点击提示原因）、
  响应阶段可用（发光并标注「可用」）；**长按技能按钮**可查看技能类型与完整描述；
- **响应阶段置暗**：服务端要「闪」「杀」「桃」「无懈可击」时，手牌里用不上的牌会灰化，能响应的牌保持明亮；
- 服务端要求选目标时（`【选择目标】` 前缀提示），直接点击席位即可，确认后把目标 ID 回传；
- 确认 / 取消 / PASS 等操作按钮集中在提示条**中央**，不再贴右边缘；
- 响应倒计时圆环（常规 25 秒，无懈 5 秒），超时自动放弃。

对局页支持：

- **拖拽出牌**：把手牌拖到对手席位上即可指定目标；
- **点选出牌**：先点手牌，再点席位，最后点「确定」；
- **技能按钮**：仁德 / 制衡 / 除害 / 丈八出杀（按武将或武器动态出现）；
- **响应倒计时**：圆形进度条显示服务端等待时间，超时自动 PASS；
- **身份与阶段**：顶部显示自己的身份，席位卡显示当前回合、阶段、体力条、横置/标记、明置身份（主公/阵亡者）；
- **弹窗**：五谷选牌、拆牌/顺手选区域、火攻展示、拼点、判定牌动画；
- **战况日志**：右侧抽屉查看完整对局记录。

## 素材说明

`assets/heroes/*.jpg` 为武将**将面立绘**，取自「三国杀 WIKI」（`wiki.biligame.com/msgs`）的公开武将页，
仅用于本地学习与局域网联机娱乐，版权归游卡桌游 / 哔哩哔哩 WIKI 原作者所有，请勿用于商业用途。
如需替换为自己的素材，把同名 `.jpg` 丢进 `assets/heroes/` 即可（没有图片的武将会自动显示势力色占位卡面）。

## 与服务端的约定

- 收到 `SYNC_STATE` 即整体刷新本地状态，字段为 `键:值|键:值`（武将/HP/DECK/SKILLS/EQUIP/JUDGE/MARKS/OPPONENTS/CARDS/TURN/PHASE/ROLE/ALIVEC/ROUND/TIMEOUT）。
- 所有对服务端询问的回应都通过 `RESPOND_CARD` 发送，格式见服务端 README。
- `LEAVE_ROOM` 表示离开房间但保持连接（回到大厅可继续建房）；`DISCONNECT` 才会真正断开。
